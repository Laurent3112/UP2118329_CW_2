# Q3 – Research Investigation: Training Dataset Size

This folder contains the solution for **Question 3** of the coursework.

Q3 takes a research-style approach and investigates how **neural network
performance depends on the size of the training dataset**.

The notebook:
- reuses the neural network architecture from Q2,
- trains models on progressively larger subsets of the training data,
- evaluates performance on a fixed test set,
- visualises the relationship between dataset size and accuracy,
- discusses the observed trends.

This investigation highlights the importance of training data volume in modern
machine learning applications.
