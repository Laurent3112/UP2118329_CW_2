# Q1 – Traditional Machine Learning Baseline

This folder contains the solution for **Question 1** of the coursework.

The aim of Q1 is to establish a **traditional machine learning baseline** for the
star–galaxy–QSO classification task using the SDSS dataset.

The notebook:
- loads and inspects the dataset,
- applies preprocessing (splitting, scaling, label encoding),
- trains a standard multiclass classifier,
- evaluates performance using accuracy and a confusion matrix.

This baseline model provides a reference point for comparison with the neural
network approach implemented in Q2.
