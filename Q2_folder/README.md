# Q2 – Neural Network Classifier

This folder contains the solution for **Question 2** of the coursework.

In Q2, a **feed-forward neural network** is implemented using PyTorch to solve the
same star–galaxy–QSO classification problem as in Q1.

The notebook:
- reuses the same dataset and preprocessing pipeline as Q1,
- defines a neural network architecture,
- trains the model using backpropagation,
- evaluates performance on validation and test sets,
- compares results with the traditional baseline.

This section explores whether a neural network can improve classification
performance over traditional methods.
